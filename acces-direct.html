Burger Social Club

Bienvenue dans l'application de gestion pour Burger Social Club. Cette page vous permet de démarrer l'application et d'y accéder directement.

Accéder au tableau de bord

Instructions

  1. Cliquez sur le bouton "Démarrer l'application" ci-dessus
  2. Attendez que l'application démarre (cela peut prendre quelques secondes)
  3. Une fois l'application démarrée, cliquez sur "Accéder au tableau de bord"
  4. Si vous rencontrez des problèmes, essayez de démarrer l'application manuellement en exécutant npm run dev dans le dossier frontend
